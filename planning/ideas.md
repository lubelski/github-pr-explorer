# Ideas

Ideas raised for github-pr-explorer. None is a plan. An idea moves to [PLAN.md](../PLAN.md) when the owner says to pursue it.

- **A Summary block.** A generated summary of what a pull request changes and where a reviewer should look. It would be one more block, placed or left out like any other. Raised because the owner said "we have AI now".
- **Describe the layout you want.** Type "put checks and owners on the left, hide the timeline" and get a layout to adjust by hand. The layout is data, so a model can write it.
- **Layouts kept in the repo.** A team commits its layouts and rules to its own repository, so every teammate's app picks them up.
- **A model reads what the APIs do not give.** Where the web page shows something no API supplies, a model could pull it out of the page. This depends on what `planning/research/github-data-sources.md` finds is missing.
- **Blocks that are not from GitHub.** A linked ticket from the team's tracker, a deploy preview, or a dashboard, as a block next to GitHub's own data.
- **Notifications from the index.** A saved view could notify when a pull request enters or leaves it. The vision says this is a consequence of the index and not the product.
